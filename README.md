# Helpdesk Ticketing System Lab

## Objective
This project simulates a real-world IT helpdesk environment using Freshdesk and a Windows 10 virtual machine. The purpose of this lab was to practice ticket lifecycle management, troubleshooting workflows, prioritization, and professional documentation skills commonly used in IT support environments.

---

## Tools Used
- Freshdesk
- VirtualBox
- Windows 10 Virtual Machine

---

## Skills Practiced
- Ticket lifecycle management
- Helpdesk documentation
- Troubleshooting methodology
- Ticket prioritization
- VPN and networking concepts
- Account access troubleshooting
- Security awareness and phishing escalation

---

## Ticket Categories

- Hardware Troubleshooting
- Software Support
